## 📌 Project Overview

This project is a **Power BI Sales Dashboard** designed to transform
sales data into meaningful business insights.

The dashboard focuses on presenting sales performance in an interactive
and easy-to-understand format, helping users explore trends, compare
categories, and identify business opportunities.

## 🎯 Objectives

-   Analyze overall sales performance
-   Track key business metrics
-   Identify sales trends and patterns
-   Compare product/category performance
-   Analyze regional performance
-   Support data-driven business decisions
-   Present complex data through a clean, interactive dashboard

### Power BI Template

**`Sales DashBoard.pbit`** is the Power BI template file included in
this repository.

> **Note:** A `.pbit` file is a Power BI template. Depending on how the
> template was created, users may need to provide or reconnect the
> underlying data source when opening it.

## 🚀 How to Use

1.  Download **`Sales DashBoard.pbit`** from this repository.
2.  Open the file using **Microsoft Power BI Desktop**.
3.  If prompted, configure or reconnect the required data source.
4.  Refresh the data.
5.  Explore the dashboard using the available filters and visuals.
